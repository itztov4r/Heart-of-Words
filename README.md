# Heart of Words ❤️

An animated heart made of love words in different languages, built with HTML, CSS and JavaScript.

## Features

- Words fly into place to form a heart.
- Double heartbeat, moving glow and drifting sparks.
- Automatic animation loop.
- Change words and color with the pencil button.
- Tap the heart or press Space to replay.
- Responsive and works offline, with no dependencies.
- Respects your system's reduced motion preference.

## Open locally

Download the files and open `index.html` in a browser.

## GitHub Pages

Open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/ (root)**, then save.

## Animations disabled?

On Windows 11, enable **Settings → Accessibility → Visual effects → Animation effects**, then reopen your browser.
